DRAGONHOLD
==========
Rescue Princess Elowen from Aurex, the Gilded Wyrm.

PLAY ON YOUR OWN
  1. Unzip this folder (right-click the zip > Extract All).
  2. Double-click index.html. The game opens in your web browser.
  Your game saves in that browser on this computer.
  Needs a keyboard and mouse. Works best in Chrome or Edge.

PLAY TOGETHER (up to 3 players)
  Easiest: one friend hosts and sends everyone their link. You don't need
  to download anything to join, just open the link and pick "Join game".

  To host co-op yourself on Windows:
  1. Install Node.js (LTS) from https://nodejs.org
  2. Install Cloudflare Tunnel: open PowerShell and run
       winget install Cloudflare.cloudflared
  3. Double-click "Start Co-op.bat" in this folder.
  4. A window shows two links: one for you, one to send to friends.
  5. In the game: Play together > Host game, then tell friends the room code.
  Keep that window open while you play. Closing it stops the server.

CONTROLS
  A / D move, W or Space jump, mouse to aim, left click to use the selected item
  E inventory and crafting, Q / R drink health / mana potion, F talk and use
  M world map, J boss log, 1-9 and 0 choose a hotbar slot, Esc menu and saving
